# INS-NAT-FINAL-005 — Public copy contract

## Required safe terms

- State credential
- Line of authority
- Carrier appointment
- CMS Marketplace registration evidence
- Regulatory & Enforcement History
- Complaint Data
- Sources currently included in our research

## Safe coverage / absence language

- Research currently includes the official sources listed below as of [date].
- No matched regulatory action was found in the sources currently included in our research as of [date].
- Official records can change. Re-check licenses on the state regulator site.
- Source coverage varies by jurisdiction. Missing data is not evidence of absence.
- Licensed in X jurisdictions in the sources currently included.
- Appointment coverage in currently included sources is incomplete. Missing appointment rows are not evidence of zero appointments.
- CMS Marketplace registration is not a state license.
- Complaint data does not by itself establish a regulatory violation or enforcement finding.
- Legal-insurer complaint statistics are not inherited by agency profiles.

## Forbidden unless exact evidence proves the statement

- verified expert
- approved insurer
- clean / Clean record
- safe
- best
- independent agent
- captive agent
- No complaints ever
- No regulatory issues
- Serves X states (unless service evidence actually proves it)
- 0 appointments (when source coverage is incomplete)
- disciplinary action / violation / misconduct / final order / finding — **from TDI complaint-index data**

## Indexing

- No people indexing
- No legal-insurer indexing
- No group/brand indexing
- Agency indexability remains fail-closed for graph agencies
- Existing public provider pages must not increase in count accidentally
