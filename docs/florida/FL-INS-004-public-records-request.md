# FL-INS-004 — public records requests (not sent)

**Required: YES** for Civil Remedy Notices and for OIR examination / order metadata.  
**Submitted: NO.** Drafts only. Do not treat as filed or received.

## 1. Civil Remedy Notice machine-readable export

**Channel:** Florida Department of Financial Services public-records portal  
https://myfloridacfo.com/publicrecords  

Also: Civil Remedy section email `civilremedy@myfloridacfo.com` (operational questions only; the records request itself goes through the public-records portal).

**Exact request text:**

Please provide, in a machine-readable table (CSV, Excel, or delimited text), Civil Remedy Notices of Insurer Violation accepted by the Department under section 624.155, Florida Statutes, for all available years, including where maintained and non-confidential:

- DFS File / filing number  
- filing accepted date  
- insurer legal name  
- NAIC Company Code, if maintained  
- Florida Company Code (OIR), if maintained  
- type of insurance  
- statutory provision(s) cited  
- current status of the notice (open, withdrawn, or other status the Department maintains)  

Do not include Social Security numbers, dates of birth, medical diagnoses, or other personal identifying information of individual claimants, insureds, or attorneys beyond what the Department already publishes on the public Civil Remedy search. This request is for the Department’s structured filing index, not for a custom legal opinion.

## 2. OIR examination metadata

**Channel:** Florida Office of Insurance Regulation records custodian via https://floir.gov (agency public-records process; OIR is not DFS — do not file this on the DFS portal).

**Exact request text:**

Please provide a machine-readable catalog of completed market-conduct examination reports and completed financial examination reports published by the Office, including where maintained:

- official company name  
- NAIC Company Code  
- Florida Company Code  
- examination type (market conduct vs financial)  
- examination as-of or scope period  
- report issued / published date  
- public document URL or document identifier  
- whether the published document is a final report  

Please keep market-conduct examinations and financial examinations in separate rows or an explicit type column. Premium-finance and other non-insurer examinees should remain identified as such and should include NAIC / Florida Company Code only if the Office maintains those identifiers for that entity.

## 3. Company administrative / final orders

**Channel:** same OIR records process as item 2.

**Exact request text:**

Please provide a machine-readable catalog of Office administrative orders, consent orders, and final orders directed to insurers or other risk-bearing entities, including where maintained:

- case / order number  
- order type (final order, consent order, emergency order, or other official type)  
- whether the order is final  
- effective date  
- company legal name  
- NAIC Company Code  
- Florida Company Code  
- public document URL or document identifier  

Do not include employee personnel files or information exempt under Chapter 119, Florida Statutes.

## Status

**Not submitted.** Prepared only because the public CRN system is search-only and OIR exam/order listings do not expose NAIC / Florida Company Code as bulk columns.
