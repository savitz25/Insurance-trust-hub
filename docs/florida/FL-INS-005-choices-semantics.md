# FL-INS-005 — CHOICES semantics

CHOICES values are **illustrative/sample comparison values** from OIR, based on approved filings for pre-defined examples (homeowners/auto) or interactive inputs (Medigap / small-group).

They are **not**:

- a consumer-specific quote
- a guaranteed premium
- a binding offer
- “your rate” / “expected rate” / “cheapest insurer”

Safe copy: “Sample premium shown in Florida OIR CHOICES for this profile and location.”

Store, when a structured extract exists: sample profile, coverage assumptions, county, company, premium, effective period, source clock `choices`.

No ranking sort in this task. Trade-secret companies are omitted by OIR.

Homeowners ≠ auto ≠ Medigap ≠ small-group health. Medigap ≠ Medicare Advantage ≠ Part D.
