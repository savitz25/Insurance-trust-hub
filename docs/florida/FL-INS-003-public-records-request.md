# FL-INS-003 — public records request (not sent)

**Required: YES.** No public machine-readable DFS/OIR file joins Appointing Entity Number to NAIC or Florida Company Code. This draft is not a submitted request.

## Recipients / channels

1. Florida Department of Financial Services, Division of Insurance Agent and Agency Services, Bureau of Licensing — public records via https://www.myfloridacfo.com (AskDFS / Agency public-records portal).
2. Florida Office of Insurance Regulation, Records Custodian — https://floir.gov public-records process.

## Request language

Please provide, in a machine-readable table (CSV or Excel), the current list of Florida appointing entities known to DFS eAppoint / licensing, including where available and non-confidential:

- DFS Appointing Entity Number  
- legal entity name  
- Florida Company Code (OIR)  
- NAIC Company Code  
- FEIN  
- official entity type (insurer, MGA, warranty, self-insurer, government, other)  
- current status  
- effective / expiration dates if maintained  

Do not include licensee Social Security numbers, dates of birth, or other personal identifying information of individual agents. This request is for entity-level appointing organizations only.

## Status

**Not submitted.** Prepared only. Do not treat as received or available.
