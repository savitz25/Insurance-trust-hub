# FL-INS-005 — Surplus-lines semantics

Keep distinct:

1. Surplus-lines **agent license** (DFS)
2. Surplus-lines **insurer eligibility** (OIR directories FSLSO points to)
3. Surplus-lines **premium/policy activity** (FSLSO monthly snapshot)
4. **Admitted** insurer status (OIR P&C / L&H, not surplus-lines XML)

Eligibility is a market-status observation. It does not mean admitted.

Attach eligible insurers by exact NAIC (or FL CoCode already mapped). Name-only hold.

FSLSO premium presence in a period ≠ current authorization and ≠ service territory.

Official eligible lists are OIR Active Company Search types: Surplus Lines; Federally Authorized; Aviation/Wet Marine. Plus NAIC Quarterly Listing of Alien Insurers (IID), which is not the admitted spine.
